EHR agent

On-device FHIR agent

Ask a health record a question, privately.

A 1.7-billion-parameter model reads a synthetic patient chart with FHIR searches and answers with the records it relied on. The model, the chart and every search run in this browser on WebGPU. Nothing leaves this device.

  • Private Nothing leaves this device. No server sees the chart or your questions.
  • On-device Runs on your GPU with WebGPU, about 127 tokens a second on an M1 Max.
  • Grounded Cites the FHIR records it used, and is graded against the benchmark.
